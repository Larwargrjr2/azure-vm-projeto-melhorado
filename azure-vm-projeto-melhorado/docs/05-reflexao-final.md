# 05 — Reflexão final

Este laboratório reforça a ideia de que a criação de uma máquina virtual exige mais do que escolher um sistema operacional. A VM participa de uma arquitetura composta por computação, armazenamento e rede, e seu acesso precisa ser controlado por regras de segurança.

Outro aprendizado importante é o ciclo de vida: planejar, provisionar, validar, utilizar, monitorar e remover os recursos quando o objetivo do laboratório terminar. Essa visão é fundamental para evitar configurações inseguras e custos desnecessários.

Como próximo passo, os mesmos conceitos podem ser aprofundados com automação via Azure CLI, infraestrutura como código, monitoramento e redes híbridas.
