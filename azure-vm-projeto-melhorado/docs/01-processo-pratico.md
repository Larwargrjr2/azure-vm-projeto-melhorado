# 01 — Processo prático

## Objetivo

Documentar o fluxo de criação de uma Azure Virtual Machine pelo Portal do Azure.

## Fluxo

```text
Assinatura
   ↓
Resource Group
   ↓
Virtual Machine
   ↓
Imagem + Tamanho
   ↓
Discos
   ↓
Virtual Network + Subnet
   ↓
Public IP + NSG
   ↓
Revisão
   ↓
Create
   ↓
Validação
```

## Resultado esperado

Ao final do processo, a VM deve aparecer no Portal com status operacional, os recursos associados devem estar identificados e o método de conexão deve estar definido.

## Evidências recomendadas

1. Resource Group.
2. Tela de criação da VM.
3. Configuração de rede.
4. Discos.
5. Tela de revisão.
6. VM criada.
7. Tela Overview/Networking.
